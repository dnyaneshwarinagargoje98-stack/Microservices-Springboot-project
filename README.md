# Spring Boot Microservices Project

This repository contains multiple Spring Boot Microservices developed using Java and Spring Boot.

The project demonstrates basic microservices architecture with independent services running on different ports.

# Microservices Included
1. Address Service
2. Product Service
# Technologies Used
- Java 8
- Spring Boot
- Spring Web
- Maven
- REST APIs
- Git & GitHub
